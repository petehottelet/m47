# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

From the existing PRD: people making original retro terminal dashboards, maker
panels, agent-generated interfaces, and themed everyday browsing.

## Product Purpose

M47 generates interfaces from content and dimensions using one deterministic
engine, exposed as a library, CLI, agent skill, generator website, and extensions.

## Capabilities and Constraints

The user requested the full project improved and built, a private GitHub repository,
an MIT license, and concrete publishing paths. Public publication is a later step.
No server, accounts, analytics, downloaded executable code, or copied show assets.
Existing Antonio font and original artwork are the available visual assets.

## Brand Commitments

Preserve M47 and the existing curved retro terminal visual language described by
the project PRD. `swept` is a historical codename, not another product.

## Implementation assumptions

The optional scope question did not receive an answer during independent work.
Proceeding from the explicit “build ... everything” brief with all five product
surfaces. The existing plain JavaScript/static architecture is retained and shared
through ESM modules; no framework or backend is necessary.

## Accessibility & Inclusion

Readable body text, semantic controls, visible keyboard focus, sufficient contrast,
reduced motion, and reversible page styling. Generated demo values must be labeled.
