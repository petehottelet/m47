# Ten forward-evaluation prompts

Run these independently in Codex and Claude before claiming the original PRD's
two-agent ship gate. Automated fixtures alone do not constitute that evaluation.

1. Make a 1280×800 observatory dashboard with three metrics and a queue table.
2. Make a portrait 600×1000 survey notebook with long prose.
3. Make a 1920×700 receiver console with channel meters.
4. Make a 480×240 instrument widget with one labeled state.
5. Make a 1600×2400 poster from a supplied table, exporting SVG.
6. Apply M47 tokens to an existing form while preserving its submit behavior.
7. Restyle existing application code without changing its event handlers.
8. Make a README SVG graphic with title, labels, and accessible description.
9. Convert a local article HTML file into a readable standalone M47 page.
10. Make an alert variant with clear textual state and no autoplay sound.

Record input, generated artifact, static-check output, viewport screenshots,
manual rubric violations, and repairs. Never mark an unevaluated task as passed.
