Generate a panel here, use M47 in your terminal, add its skill to an agent, or bring the look into your browser.

Use the workshop

Choose an example, edit its JSON, set a canvas and export. HTML includes the font and scrolls for long content. SVG and PNG use a fixed canvas; increase its height if the content will not fit. Theme CSS exports the semantic color tokens.

Install the workshop from your browser's app menu when available. Once loaded online, its application files are cached for offline use. Drafts stay on this device. Copying a share link includes the panel content in the link.

Run the CLI

From a source checkout with Node 22 or later:

npm ci
npm run build
node cli/index.js generate --spec dist/example.json --out panel.html
node cli/index.js generate --spec dist/example.json --out panel.png

The npm package name configured by the project is @petehottelet/m47. Registry publication is separate; do not assume it is already available.

Install an extension locally

Run the build, open chrome://extensions or edge://extensions, enable Developer mode, and load dist/chrome. Install dist/newtab-chrome separately if you want the new-tab dashboard.

For Firefox, open about:debugging, select This Firefox, and load dist/firefox/manifest.json temporarily. Persistent distribution needs Mozilla signing. Host access may need to be granted in the extension's permission controls.

Install the agent skill

Extract m47-v0.2.0-skill.zip. Place its m47 folder in your agent's skills directory. The bundle contains the guide, engine, CLI, fonts, and examples.

Publish

The source repository is private. Public stores, npm packages, and hosted websites are separate distribution choices. The repository's docs/PUBLISHING.md contains the commands, asset names, account steps, store copy, and current documentation links.

For static hosts use build command npm ci && npm run build and output directory dist/web. The public privacy-policy URL will be /privacy.html on that host. A private GitHub file is not a public privacy-policy URL.
