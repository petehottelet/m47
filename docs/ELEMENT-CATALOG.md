## Geometry rules

Radial dividers use a constant linear width across rings; deliberate open sectors remain distinct from dividers. Connection and measurement vectors have solid dots at both terminals. Labels must fit their actual colored shapes, including rounded corners. Adjacent command segments have flat facing edges; round only exposed ends. Nested brackets retain clearance from surrounding rails.
